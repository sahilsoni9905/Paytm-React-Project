API DETAILS DOCUMENTATION
================================================================================

CHATBOT APIs (FastAPI - Port 9000)
================================================================================
Base URL: http://localhost:9000
These are separate from the main backend APIs and run on FastAPI with Gemini AI integration.

14. CHAT WITH AI BOT
================================================================================
Endpoint: POST /chat
Description: Main chatbot endpoint powered by Gemini AI for natural language conversations
Authentication: Not required (but user_token needed for user-specific actions)

Request Body (JSON):
{
    "message": "Hey, can you show me my account details?",
    "user_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

Supported Intents:
- get_user_details: "hey give my detail", "what's my name?", "show my info"
- general_chat: "hello", "hi", "how are you?"

Success Response (200) - User Details:
{
    "response": "Hello! I'd be happy to help you with your account details. Based on your profile, here's your information:\n\n👤 **Name:** John Doe\n📧 **Email:** john@example.com\n\nIs there anything specific you'd like to know more about?",
    "action_taken": "fetched_user_details_with_ai",
    "intent_detected": {
        "intent": "user_details",
        "action": "get_user_details", 
        "confidence": "high",
        "tone": "formal",
        "specific_request": "user details",
        "extracted_info": {}
    }
}

Success Response (200) - General Chat:
{
    "response": "Hello! I'm your Paytm assistant. I can help you with your account details. Try asking 'What's my name?' or 'Show my info'.",
    "action_taken": "general_conversation",
    "intent_detected": {
        "intent": "general",
        "action": "general_chat",
        "confidence": "high", 
        "tone": "friendly"
    }
}

Success Response (200) - Unknown Intent:
{
    "response": "I understand you're asking about something, but I'm still learning! \n\nRight now I can help you with:\n🔍 Your account details - Try: \"hey give my detail\" or \"what's my info?\"\n\nMore features coming soon! 🚀",
    "action_taken": "unknown_intent",
    "intent_detected": {
        "intent": "...",
        "action": "...",
        "confidence": "..."
    }
}

Error Response (500):
{
    "detail": "Something went wrong: Cannot connect to backend. Make sure your Node.js server is running on port 3000"
}

3. UPDATE USER PROFILE
================================================================================
Endpoint: PUT /user/update
Description: Update user's first and last name
Authentication: Required (Bearer token)

Headers:
Authorization: Bearer <jwt_token>

Request Body (JSON):
{
    "firstName": "John",
    "lastName": "Smith"
}

Success Response (200):
{
    "message": "Updated successfully"
}

Error Response (400):
{
    "message": "First name and last name are required"
}

5. UPDATE PROFILE PICTURE
================================================================================
Endpoint: POST /user/updateProfilePic
Description: Upload and update user's profile picture
Authentication: Required (Bearer token)

Headers:
Authorization: Bearer <jwt_token>
Content-Type: multipart/form-data

Request Body (Form Data):
file: <image_file> (max 500KB)

Success Response (200):
{
    "msg": "Photo uploaded",
    "url": "https://cloudinary.com/new_image.jpg"
}

Error Response (500):
{
    "message": "Error uploading photo",
    "error": "File size too large"
}
